HazeAC Admin Panel - FiveM NUI

This is the HazeAC Admin Panel for FiveM.

The panel uses FiveM's NUI (Native UI) system and runs in-game.

Note: This HTML file is just a placeholder showing build instructions. The actual admin panel is built with React and runs in-game via FiveM's NUI system.

Build Instructions / Istruzioni Build

1. Install dependencies: cd web-panel && npm install

2. Build for production: npm run build

3. The built files will be in the nui folder

4. The panel will be accessible in-game via the admin command

In-Game Usage / Uso In-Game

To open the panel in-game, use the command:

/hazeac_panel

Requires ACE permission: haze_ac.admin
